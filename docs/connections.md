# 连接管理：多服务器 / API Connect

状态：`[进行中]`。

---

## 1. 目标

- 一个 App 可以保存多个 opencode 服务器（本机、局域网、远程/隧道）；
- 随时切换，不把两个服务器的会话/流混在一起；
- **本机永远排第一**，远程按最近使用排序；
- **记住上次连接的服务器**，下次启动优先恢复它；
- 明确的“新建连接（API）”入口，而不是只能先断开再手输。

---

## 2. 连接模型

```text
Connection {
  id           // 稳定 ID（可用 URL 规范化）
  name         // 可选显示名
  baseUrl      // http://host:port
  username     // 固定 opencode
  password     // 服务器密码
  lastUsedAt   // 最近使用时间
  source       // 手动 / 本机 / 配对链接
}
```

- 本机连接使用 `127.0.0.1:<port>`；
- 局域网/远程使用 `http://<host>:<port>`；
- 密码只用于 Basic auth；配对链接换取会话令牌；
- 切换时先 `disconnect()`：取消流、清空当前会话/PTY，再 `connect()`。

---

## 3. 排序与记忆

- 连接选择器：**本机第一**，其余按 `lastUsedAt` 倒序；
- 当前连接标记“当前”；
- 启动时：
  - 上次是远程 → 直接恢复远程，不被宿主的本机 URL 覆盖；
  - 上次是本机（或首次）→ 使用宿主刚启动的本机 URL/密码；
- `connect()` 成功后才写入 `url/password` 和最近使用；失败不污染列表。

---

## 4. 新建 / 编辑 / 删除

### 新建连接

入口：

- 服务器切换器 → **新建连接**；
- 设置 → 连接 → 新建；
- 首次启动 → “连接已有服务器”。

字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| 名称 | 否 | 默认取 host:port |
| 服务器地址 | 是 | `http://host:port`；支持自动补 `http://` |
| 密码 | 否 | 空 = 无密码服务器 |
| 保存 | | 只保存，不连接 |
| 保存并连接 | | 保存后立即 ping/连接 |

### 编辑

- 可改名称、URL、密码；
- 改 URL 视为新连接（旧连接保留，除非用户删除）；
- 正在连接时改配置 → `cancelConnect()`，停在当前页。

### 删除

- 只删保存记录，不影响服务器数据；
- 删当前连接时回到连接页，不自动重连。

---

## 5. 切换行为

- 切换 = `disconnect()` + 新 `connect()`；
- 清空：当前会话、消息、会话列表、缓存、PTY、打开会话；
- 不清理：项目文件、保存的连接、主题/设置；
- 连接失败停在连接页，显示错误，不自动回退到旧服务器。

---

## 6. 安全

- 当前密码存在 `SharedPreferences` 明文；`[计划]` 用 Android Keystore 加密；
- 不在日志/崩溃报告/分享卡片里输出密码；
- URL 里的密码不允许；
- 局域网模式提示“仅可信网络”；
- 配对链接一次性、5 分钟过期。
