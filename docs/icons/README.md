# 启动图标

`> ` + 右下光标方块，两个版本只差光标：

| 版本 | 光标 |
|---|---|
| thin | 空心（远程） |
| bundle | 实心（本机运行） |
| debug | 右上角 2.4px 状态点 |

- 画布 108；主体在 66×66 安全区内。
- `>`：粗 7，圆角端点，顶点 (60,54)。
- 光标：16×14，圆角 4.4，位于 (70,60)。
- 颜色：底 `#122A3B → #08121B`；墨 `#F1F6FF`；强调 `#7CF7E3 → #23A392`；debug 点 `#7DD3FC`。

重新生成：

```sh
RESVG=/path/to/resvg python scripts/gen-app-icons.py
```
